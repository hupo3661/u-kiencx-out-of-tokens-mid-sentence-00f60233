One line, 99 characters — the error message an AI agent shows when it runs out of tokens mid-sentence:

> Error: out of tokens mid-sentence. The rest of this error message was going to be really good, but—

## What it is

The error message performs its own failure: it promises the rest was
going to be really good, then stops dead on an em dash. The flat tone of
a real error message is kept all the way through, and the cut-off is the
punchline — the reader experiences the exact failure the message is
reporting.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
